# User flow — [Producto]

*Producto · Paso 6 · Toma de: Fichas (momentos, entradas, salidas y actores)*

> El diagrama puede estar en HTML, Miro u otra herramienta. Este documento dice qué debe contener.

## Debe incluir

- **Camino feliz** de cada momento de las fichas.
- **Flujos alternos:** caminos distintos que igual llegan al objetivo (por ejemplo, cancelar).
- **Flujos de excepción:** cuando algo falla y el objetivo no se logra.
- **Permisos y puntos de entrada:** desde dónde se llega a cada pantalla.
- **Qué pasa fuera de la app:** notificaciones, sistema operativo, otras apps.
- **Reglas automáticas del sistema**, diferenciadas de las pantallas (por ejemplo, con línea punteada).

## Comprobación

- [ ] Todo paso termina en una **pantalla con nombre**, no en un estado.
- [ ] Cada momento de cada ficha aparece en el flujo.
- [ ] Hay al menos un flujo de excepción por momento.
